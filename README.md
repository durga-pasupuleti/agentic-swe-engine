# Agentic SWE Engine

Minimal Spring Boot project skeleton based on the supplied requirements.

## Requirements

- Java 21
- Maven 3.6.3 or newer

## Run

```powershell
mvn spring-boot:run
```

The API route `POST /api/v3/sdlc/jobs` is present as a `501 Not Implemented` stub. Workflow orchestration, MCP communication, persistence, and request handling are intentionally not implemented yet.
